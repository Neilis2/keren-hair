# KEREN'S Hair

Landing page para KEREN'S Hair, con servicio a domicilio, proceso de reserva y formulario para enviar la solicitud por WhatsApp.

## Características

- Diseño de una sola página con secciones de servicios, portafolio, proceso de reserva y política.
- Formulario de reserva que reúne los datos clave y abre WhatsApp con un mensaje ya preparado.
- Layout responsive y visual de marca cálida y elegante.

## Estructura del proyecto

```text
.
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── script.js
└── assets/
    └── images/
        ├── hero/
        ├── brand/
        └── portfolio/
            ├── mujeres/
            ├── hombres/
            └── ninos/
```

- `index.html`: estructura de la página.
- `css/styles.css`: estilos visuales y responsive.
- `js/script.js`: lógica del formulario y apertura de WhatsApp.
- `assets/images/hero/`: imágenes de portada.
- `assets/images/brand/`: logo y recursos de marca.
- `assets/images/portfolio/mujeres/`: estilos y trabajos para mujeres.
- `assets/images/portfolio/hombres/`: estilos y trabajos para hombres.
- `assets/images/portfolio/ninos/`: estilos y trabajos para niños.

## Cómo usarlo

1. Abre `index.html` en el navegador.
2. Ajusta el número de WhatsApp real en `js/script.js`.
3. Si deseas, puedes desplegarlo en GitHub Pages, Netlify o Vercel.

## Requisitos

No requiere dependencias ni build tools.

## Nota

El número de WhatsApp se deja configurado como ejemplo para que puedas cambiarlo fácilmente antes de publicar.
